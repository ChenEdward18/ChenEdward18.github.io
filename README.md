# 吴叶琛的个人主页

这是一个只使用 HTML、CSS 和 JavaScript 制作的个人介绍网页，不需要安装复杂框架。

## 文件说明

- `index.html`：网页的栏目、文字和链接。
- `styles.css`：配色、排版、卡片、动画和手机适配。
- `script.js`：中英文切换、深浅主题、复制按钮、手机菜单等交互。
- `assets/`：以后可以放项目图片和 PDF 简历。

## 本地查看

最简单的方法是双击 `index.html`。如果复制按钮受浏览器安全限制，可以使用本地网页服务器预览。

## 加入简历

把简历命名为 `resume.pdf` 放入 `assets` 文件夹，再将首页的简历按钮改为指向 `assets/resume.pdf` 的链接即可。
